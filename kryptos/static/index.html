EVIDENCE BEFORE CONCLUSIONS

Know what a fit means.

A practical guide to using this research workbench.

01

Start with a declared model

A cipher, alphabet, route and key schedule define one hypothesis. A completed search applies only to its recorded bounds. An interrupted search cannot exclude the family.

02

Read candidates critically

The public K4 clues constrain 24 of 97 letters. Even an exact fit and a successful re-encryption can leave many valid plaintexts. A language score is a ranking aid, never an authentication test.

03

Keep K5 assumptions explicit

This workbench has no authenticated public K5 ciphertext preset. Supply and label your own hypothesis. K4 clues are not automatically transferred to K5.

04

Use the right compute path

Exact constraint solvers run on the CPU. CUDA is available only for supported accelerated families when the local engine detects a compatible device. More workers or a GPU do not guarantee faster useful results.
